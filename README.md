# Smilebot Portfolio

Public portfolio and booking website for Aaron "Smiley" Cate.

## Source of Truth

Read [`SOURCE_OF_TRUTH.md`](./SOURCE_OF_TRUTH.md) before making changes. Reusable public contact values and social links live in [`data/siteContent.js`](./data/siteContent.js).

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Verification

Stop the development server before running the production build:

```bash
npm run build
```

Check the public routes at phone and desktop widths after content or layout changes.
